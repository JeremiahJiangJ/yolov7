Drag a box / its edgesmove / resize. All selected boxes move together. The correction spreads to auto boxes as set at the top (drift: tapers to the keyframes on either side)
Alt+dragmove the selected tracks by the same amount on every frame of the range
Ttrack the selection forward to the next keyframe (its position corrects the run) or 300 frames
Kmake the current box a keyframe (locked)
O / Coutside (object leaves / comes back) / occluded
Alt+1–9toggle a tag. Tags, occluded and outside apply from this frame to the next keyframe, or to the whole range when this frame is inside the selected range
[ / ] / \range start / end at this frame / clear the range (Shift+drag on the timeline also sets it)
R / U / Lrange: re-interpolate (drop auto boxes) / unlock (keyframes → auto) / lock (auto → keyframes)
